# 朱红留白搜索界面

## 设计范围

- 首页：暖白背景、宋体主标题、朱红搜索按钮；不展示最近浏览、分类或来源。
- 结果页：桌面默认三列，紧凑视图四列；平板两列，手机一列。完整容纳 16:9 与其他比例素材；保留标题、页码、后端匹配度。
- 选择：44px 操作热区、28px 可见勾选框；点击预览与勾选分离。选中状态使用朱红细框与淡底，底部操作栏按需出现。
- 已选弹窗：跨查询保留、调整导出顺序、移除、预览、导出。最多 200 页，与后端上限一致。
- 预览：主内容独立加载，相关页异步加载；切页更新标题，阻止过期响应覆盖。原生 dialog 支持 Esc、焦点约束及关闭后的焦点恢复，方向键切换搜索结果。
- 搜索：查询写入路由，保留内存结果；取消请求，屏蔽过期响应，错误重试，空状态，零分和缺失分数分开显示。中文输入法确认候选时不误提交。

## 验收

`cd frontend && npm run check`

交互测试覆盖单次提交、无分类传参、勾选不打开预览、导出顺序、过期请求、取消恢复、跨挂载选择、缺失/零分、错误重试、空结果、更多结果、主预览独立加载、方向键及标题更新、Esc、选页上限和清理。

浏览器验收使用本地模拟 API；不把示例分数当作真实检索质量。发布前检查真实登录、页面图片、查询、导出接口。匹配度与后端算法未修改。
