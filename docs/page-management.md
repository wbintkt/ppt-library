# 页级素材管理、标签与增量相似检测

## 使用方式

- 文件详情页：勾选页面后批量删除；“追加页面”上传同尺寸 PPTX，留空导入全部可见页，或填写 `1,3-5`。新页面追加到末尾。
- 删除和追加后，“下载当前页面”反映当前页面清单；搜索导出仍保留原生可编辑内容及所选顺序。
- 新上传/追加页面自动生成 1–5 个内容标签。词库先检查同名，再通过向量召回和模型确认同义标签，复用已有词；没有可提取文字的页面使用图片理解。
- 页面标签不参与搜索的向量输入、关键词加分、全文召回和排除降权。文件标签仍可作为显式筛选条件。
- “相似检测”只显示新上传/追加批次与上传时已有页面的对比，不扫描存量彼此的重复。必须等本批页面全部向量化完成才运行。
- 对比图支持放大预览；可保留新页、保留已有页、或两页都保留。删除前确认，删除页相关的其他待处理组合会同步失效。
- 未配置密钥/向量或标签生成失败时显示明确状态，可点击“重试未完成项”。已有文件可手动“生成页面标签”，不会因此触发存量重复扫描。

## 数据与一致性

新增表通过现有 `Base.metadata.create_all` 创建，不改写存量页面内容：

- `managed_files`：页级编辑标记及版本。
- `page_sources`：稳定页面 ID 到不可变 PPTX 源文件、可见页码、原可见页数的对应关系。
- `page_tags`：规范标签词库及语义向量。
- `ingest_runs`：仅新上传/追加建立检测批次，记录新页 ID、已有页面 ID 上界与处理状态。
- `duplicate_pairs`：新旧页面配对、相似度、依据和处理状态。

首次编辑时记录全部旧页来源，删除后只重排显示页码，不改变保留页面的 ID。源文件保留用于合并与恢复；“重索引”不会从原始文件恢复被删页面。空文件可继续追加，下载时提示无页面。

同文件的上传/删除使用行锁，处理期间不允许再次修改；标签词库写入使用事务锁，防止并发生成重复词。文件的标签任务使用独占锁避免重复执行。

相似检测标准：图像哈希完全一致；或余弦相似度至少 0.95 且正文三字片段重合度至少 0.80（双方正文至少 40 字）。同主题、同模板不足以判定重复。所有命中只提醒，不自动删除。无向量的旧页面仍可用相同图像匹配，语义比较依赖已有向量。

大文件导出按需流式复制媒体，响应从临时文件流式发送；补齐包级与跨文件关系，确保导出文件可以再次解析。

## 发布与验证

发布前备份数据库、源代码及前端静态文件。先停止工作进程并确认没有处理中任务，更新后端并建立新增表，再启动后端和工作进程，最后替换前端静态文件。

本地回归覆盖隐藏页、来源映射、选中顺序、标签不影响搜索、低相似内容不误判、权限校验，以及界面删除确认与保留操作。

独立 PostgreSQL 测试库和真实 LibreOffice 测试：上传、删除、追加、稳定 ID、下载当前文件、重索引、增量重复提醒、保留操作、向量失败状态与词库复用。运行测试需显式设置 `TEST_MANAGEMENT_DATABASE_URL`，数据库名必须以 `_test` 结尾；测试会清空该测试库的表。

真实模型已验证“无人机巡查 / 无人机巡逻”复用同一词条，并验证单页最多生成 5 个标签。存量文件不自动补标签或生成重复提醒。
